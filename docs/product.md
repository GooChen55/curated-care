# 产品范围

Curated Care 以购物与售后为一个连续流程：用户购买商品，在同一界面咨询资料或提交售后申请，运营人员处理商品、发货、知识文档和退款审核。

## 当前能力

| 业务 | 实现 |
|---|---|
| 账户 | 演示用户与管理员、加盐密码、会话令牌与退出撤销 |
| 商城 | 商品查询、搜索与分类、购物车、订单与价格快照 |
| 库存 | 事务扣减、固定顺序行锁、取消/审核退款后恢复 |
| 售后 | 未发货已付款订单退款、原因收集、明确确认、审核与审计 |
| 助手 | 对象校验、订单/物流工具、暂停与恢复、历史与请求去重 |
| 知识 | Markdown/文本导入、切片、来源、BM25、可选向量融合 |
| 部署 | 本地统一进程管理、Docker Compose、持久化数据 |

## 运行边界

支付、物流与资金退款目前为演示流程。每个订单一条退款申请；自动退款限于未发货已付款订单。已发货售后、部分退款、驳回后重新申请、支付超时关单与真实渠道对接属于扩展需求。

助手以单 worker 运行。多实例部署需要增加分布式并发控制。模型接口格式通过模拟响应验证，真实模型效果、费用与可用性需在配置实际服务后评测。

当前知识管理支持 Markdown 和纯文本。PDF/OCR、图检索与重排服务不属于当前内置运行栈，可通过外部检索契约扩展。
